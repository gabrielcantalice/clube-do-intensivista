Como este painel funciona

Este é um protótipo funcional: os dados que você cadastrar aqui (eventos, cursos, aulas, materiais, comunicados) ficam salvos neste navegador e já aparecem refletidos na Área do aluno. Cursos, materiais e eventos novos também aparecem automaticamente nas páginas públicas do site (Cursos, Materiais e Agenda). Quando o site for para produção, essas mesmas telas passarão a salvar em um banco de dados real, acessível de qualquer dispositivo — e o login do admin e do aluno passa a ser a mesma tela, com o sistema reconhecendo o perfil de cada um após entrar.
